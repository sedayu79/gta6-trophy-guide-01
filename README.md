An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: a roadmap to the platinum, missable flags, cited guides in our own words, and a checklist whose progress saves in the browser with export and import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or serve `app/` with any static file server. It works with the network off: every file it loads lives under `app/`.
